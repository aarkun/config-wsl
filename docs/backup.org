This document describes methods and scripts to manage backups of the WSL 2 and is based on [[https://www.virtualizationhowto.com/2021/01/wsl2-backup-and-restore-images-using-import-and-export/][WSL2 Backup and Restore Images using Import and Export]].

* Check for running processes with open sockets:
#+begin_src shell
  netstat -l
#+end_src

* Kill running processes
Before making a backup, all running process should be terminated and not needed (like temporary) files should be deleted:
#+begin_src shell
  ps hxo pid | xargs kill
#+end_src

* Export / Backup
Shut down the WSL and export it:
#+begin_src powershell
  wsl --shutdown
  wsl --export Debian "$backup_dir\backup.wsl2.debian.tar"
#+end_src

* Import / Restore
** Import the first time
Importing in a fresh environment, first installs a fresh distro and then imports the backup into the distro:
#+begin_src powershell
  wsl --install -d Debian
  wsl --import Debian `
    $env:LOCALAPPDATA\Packages\TheDebianProject.DebianGNULinux_76v4gfsz19hv4\LocalState\ `
    "$backup_dir\backup.wsl2.debian.tar"
#+end_src

** Reimport
Reimporting a backup needs to remove the distro, before reimporting it. After the import, the default distro and user must be set:
#+begin_src powershell
  wsl --unregister Debian
  wsl --import Debian `
    $env:LOCALAPPDATA\Packages\TheDebianProject.DebianGNULinux_76v4gfsz19hv4\LocalState\ `
    "$backup_dir\backup.wsl2.debian.tar"
  wsl --set-default Debian
  wsl --manage Debian --set-default-user kunde
#+end_src
